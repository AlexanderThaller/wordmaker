== Summary

When a variation stored in settings no longer exists (e.g. after
reinstalling the theme from a different zip), `build` returns an error.

== Location

* `src/theme/mod.rs:671-673`

== Impact

The site silently switches to the built-in look instead of the active
theme without that variation.

== Suggested fix

* Skip and log a missing variation.
