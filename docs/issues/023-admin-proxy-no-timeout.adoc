= 023: Admin proxy's upstream client has no timeout
:severity: Low
:area: wordmaker-admin
:status: fixed
:found: 2026-10-24

[horizontal]
Severity:: Low
Area:: wordmaker-admin
Status:: Fixed

== Summary

The reqwest client used to forward requests has no connect or request
timeout.

== Location

* `crates/wordmaker-admin/src/proxy.rs:38-41`

== Impact

A hung upstream ties up admin connections indefinitely.

== Suggested fix

* Set a connect timeout and a request timeout (longer for uploads).

== Resolution

The upstream client now has a 10 s connect timeout, and every forwarded
request a total timeout of 2 minutes, or 15 minutes when its body is over
1 MiB (media uploads and theme zips). A request that runs out of time gets
a 504 "the WordMaker server took too long to answer".
