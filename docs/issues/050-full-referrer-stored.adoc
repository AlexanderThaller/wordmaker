Severity:: Low
Area:: Analytics / privacy
Status:: Fixed

== Summary

The complete Referer header is stored.

== Location

* `src/analytics/sink.rs:332`

== Impact

Query strings from referring sites (search terms, tokens, email
addresses) end up in ClickHouse.

== Suggested fix

* Store only scheme, host and path, or just `referrer_host`.

== Resolution

The sink stores only the referrer's scheme, host and path: query string,
fragment and user info are removed, and a `Referer` that is not a URL is
stored as empty. `referrer_host` is unchanged. Rows written before the fix
keep their full referrers.
