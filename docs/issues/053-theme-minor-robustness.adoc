== Summary

Small correctness gaps in the theme code.

== Location

* `src/theme/mod.rs:294-299`
* `src/theme/mod.rs:412`
* `src/theme/site_css.rs:72-81`

== Impact

* `read_file` on a directory returns 500 instead of 400.
* The URL scheme check in `install_from_url` is case-sensitive
  (`HTTPS://` is rejected).
* `luminance` accepts a `+` sign through `from_str_radix` (`#+f+f+f`).

== Suggested fix

* Return 400 for directories, compare schemes case-insensitively, and
  validate hex digits (see link:004-luminance-panic-crash-loop.adoc[issue 4]).

== Resolution

* `read_file` on a folder returns 400 ("is a folder"), as `write_file`
  already did.
* `install_from_url` parses the URL with `url::Url`, which lowercases the
  scheme, so `HTTPS://` is accepted (done with
  link:006-install-theme-ssrf.adoc[issue 6]).
* `luminance` requires ASCII hex digits, so `#+f+f+f` is no longer a colour
  (done with link:004-luminance-panic-crash-loop.adoc[issue 4]).
