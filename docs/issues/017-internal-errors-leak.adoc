== Summary

`Database`, `Io` and `Internal` errors send their message to the client
(`+"database error: ..."+`). The analytics API returns the full ClickHouse
error chain. All of these endpoints need authentication.

== Location

* `src/error.rs:152`
* `src/error.rs:200`
* `src/api/analytics.rs:56`

== Impact

An API or MCP client sees file paths, SQL details or ClickHouse
internals in error responses.

== Suggested fix

* Log the details and return a generic message for 5xx responses.

== Resolution

`AppError::public_message` replaces the text of `Database`, `Io` and
`Internal` errors with `internal error`; the API and the MCP tool results
use it, and the full error still goes to the log. The analytics report
logs the ClickHouse error chain and tells the client only that analytics
cannot be read.
