= Security audit findings
:found: 2026-10-24

Findings from a security review and bug hunt of WordMaker, one file per issue.
The threat model: anyone holding the API token or an OAuth grant can already
publish raw HTML, so the issues that matter come from third-party themes,
prompt-injected MCP clients and anonymous visitors.
