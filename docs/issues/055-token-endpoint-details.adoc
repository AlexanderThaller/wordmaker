Severity:: Info

== Summary

Minor deviations, mostly mitigated by mandatory PKCE.

== Location

* `src/oauth/mod.rs:626`
* `src/oauth/mod.rs:697-704`
* `src/app.rs:100`

== Impact

* `redirect_uri` is optional at the token endpoint.
* `code_verifier` characters are not checked against the allowed set.
* `Bearer` is matched case-sensitively.
* `/oauth/token` and `/oauth/revoke` without a form content type get axum's
  plain-text 415 instead of an OAuth JSON error.
* `purge_expired` runs on every anonymous `/oauth/token` call, an
  unnecessary write per request.

== Suggested fix

* Require `redirect_uri` when it was sent at authorize, validate the
  verifier charset, match the scheme case-insensitively, return OAuth JSON
  errors, and purge on a timer.

== Resolution

All five points are addressed:

* Codes record whether the authorization request named `redirect_uri`
  (`oauth_codes.redirect_uri_sent`, in `0005_oauth_reuse.sql`). If it did,
  the token request must repeat it.
* `code_verifier` must be 43 to 128 unreserved characters
  (`A-Z a-z 0-9 - . _ ~`).
* The `Bearer` scheme is matched case-insensitively, and extra spaces
  before the token are allowed.
* `/oauth/token` and `/oauth/revoke` answer a missing or malformed form
  body with an OAuth `invalid_request` JSON error.
* Expired codes and tokens are purged every ten minutes by a task that
  `serve` starts, instead of on every token request.
